## How to Convert to PDF

### Method 1: Using HTML to PDF (Recommended)
Since we don't have direct PDF conversion tools in this environment, the easiest way is to:
1. Open `Madhan_Thalloju_Resume.html` in a web browser (double-click the file or right-click → Open with → Browser)
2. Press `Ctrl+P` (or Cmd+P on Mac) to open the print dialog
3. Select "Save as PDF" as the destination
4. Click "Save" and choose your filename and location

### Method 2: Using Markdown to PDF
If you have Pandoc installed:
```bash
pandoc Madhan_Thalloju_Resume.md -o Madhan_Thalloju_Resume.pdf
```

### Method 3: Using Online Converters
You can also use various online markdown to PDF converters:
- Upload the markdown file to: https://markdown2pdf.com/
